## semantic underlay候補の比較

![underlay候補6種の頭部比較](underlay-candidates.png)

viewerをheadlessで描画して比較した。左上から順に
`normalized-sdk5`（下地なし・基準）、`central`、`r55`、
`r55-clear60`、`clean2`、`reserved-final`。

- 下地なしの基準は額と左目上に大きな白抜けが出る。下地を入れるとこれは消える。
- `central` `r55` `r55-clear60` は星のヘアピンとお下げが消える。パーツ欠落の回帰。
- `clean2` は前髪中央に白抜けが残る。
- `reserved-final` が総合で最良。星もお下げも残り、前髪もほぼ連続する。
- ただし全候補に共通して、髪の輪郭に沿った階段状の白い縁が残る。
  描画順ではなくアトラス側の問題を示すため、下地メッシュの調整だけでは消えない。
